A LITTLE TRANSPARENCY

Two tastes, thoughtfully balanced

Afterglow looks for common ground without letting either person's taste disappear.

In this sample studio

Public cultural favorites have hand-authored tags. We match them to fictional places, favor balanced scores, then compare three-stop combinations within your sample budget. No AI model or Qloo API is called.

Use it with an agent

Afterglow provides real MCP tools for an external agent to search, plan and replan. This app has no built-in AI model, and the sample does not demonstrate a live Qloo-powered agent.

With Qloo connected

Choose actual Qloo entities from search. The server asks Qloo for nearby places for each set of cultural signals, finds the overlap, and balances their list ranks. Qloo provides the results; Afterglow creates the route interpretation.

Affinities describe aggregate cultural patterns. They are not probabilities about you or a measure of relationship compatibility. Prices, hours, travel times and availability must be checked directly.

Only the city and selected public cultural entity IDs are sent to Qloo in live mode. Saving stores the plan in this browser. There are no bookings or outgoing messages.
